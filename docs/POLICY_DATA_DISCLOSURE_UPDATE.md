# MARC policy data disclosures — 5 November 2026

## Changes

The existing website Privacy Policy and Terms were used as the starting wording, preserving the professional introduction, operator/contact, Hostinger disclosure, agreed support retention, provider disclosures and statutory-rights language. The canonical JSON was updated first, then the existing renderer synchronized the designed website and offline documents. Dates are 5 November 2026. No Swift implementation or website styling changed.

Privacy now states:

- Which system/process fields are read and why: activity displays and selected controls.
- Connecting automatically starts the Python monitoring collector; view-dependent readers and user-triggered changes are distinct. Embedded scripts travel over SSH, file transfers use SFTP, and connecting does not install a persistent MARC agent or scheduled job.
- An eligible file may be inspected locally on the Mac to determine text-editor support before text is returned for an editor/preview/download action.
- The history payload includes identifiable Mac/account/network context and activity readings. It excludes separate process lists, Terminal transcripts, file contents, control/service replies and AI prompts. Writes occur about every five seconds; two-hour row pruning occurs on the first save and about once per minute only while active. Failed writes can leave gaps; disconnecting or removing the app does not schedule deletion or erase remote data/backups.
- Process stop markers and interrupted cleanup; background cancellation is not instantaneous remote cleanup, and remote programs can continue.
- Optional local notifications: stored alert names/conditions, profile identifiers, repeat-control/delivery state; content provided to iOS, potential Lock Screen display, permission controls, and the distinction between disabling delivery and erasing saved rules/state. No MARC push-notification server or continuous background monitor is claimed.
- Settings currently opens the published website policies. Bundled resources/offline source documents can be older in an installed build; publishing a website does not update an existing app binary.

Terms adds the awake/reachable Mac and Python requirements, automatic collection/history writes and resource use, gaps and delivery limits, consequences of interrupted operations, and networks/logs generated by tools and services. Existing authorization, file-loss, process/service, AI-review, external-charge and statutory-rights clauses remain.

The detailed command inventory stays in How MARC works. The legal pages link to it; they do not repeat the inventory or use descriptions such as “plain-English explanation.”
