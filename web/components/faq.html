A few things to know.

Getting started, connecting and using MARC.

What is MARC?

MARC is an iPhone app for monitoring and managing a Mac over SSH. Check activity, manage files and processes, run terminal commands, and use supported system, service and Docker controls. It does not stream your Mac’s desktop.

What do I need to get started?

A compatible iPhone and Mac, Remote Login enabled for the Mac account you use, and a network connection between your devices. Your Mac must be awake and reachable. Monitoring and helper queries require Python 3 on the Mac; some controls require additional tools or permissions. Start with both devices on the same trusted network. Read the setup guide →

Do I need a subscription?

No subscription is required for MARC’s core monitoring, file management, terminal sessions and supported controls. External AI providers may charge for API usage.

Can I use MARC away from home?

Yes, if your iPhone has a secure network route to your Mac, such as a VPN you configure separately. MARC does not provide an internet relay or make a sleeping or disconnected Mac reachable. See connection guidance →

Do I need a MARC account?

No. Connect using your Mac account’s username and password or a supported SSH key. Your Mac account’s permissions determine which files and actions you can access.

Do I have to set up AI?

No. AI command suggestions are available only in Terminal and start Off. Monitoring, files, processes, services, Docker and system controls work without AI. You can use Ollama on your Mac or a supported API provider when you want suggestions. Review suggested commands before choosing Run. Read about AI setup and data sharing →

Does my Mac data pass through MARC’s servers?

Normal monitoring, terminal traffic and file transfers go directly between your iPhone and Mac over SSH, without a MARC-operated relay. API AI sends requests to your selected provider when you use it. Website analytics and support email are separate. Read the Privacy Policy →

Where can I get help or inspect the code?

Use the documentation for setup and feature guides, or contact support for help. MARC’s source code and public issue tracker are on GitHub. Do not post passwords, private SSH keys, API keys or sensitive logs.
