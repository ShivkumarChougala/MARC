Using MARC / Local & API AI

Local & API AI

Choose local assistance on your Mac or a supported API provider.

Understand destination approval

The first API prompt to an endpoint in the current Terminal session asks for approval of the displayed destination. Approval covers further prompts to that endpoint in that session; each generation still requires your action. Connection or relevant configuration changes invalidate approval.

Loading a built-in provider’s model catalogue asks separately. That request sends the API key, when selected, and normal connection information, but no prompt, terminal output or files. The custom provider option does not load a built-in catalogue.

Prompt requests contain the text you submit, selected model and command-generation instructions, with the selected API key in an authentication header when configured. The recipient receives your public IP address and ordinary request metadata. Terminal output, files and Mac credentials are not automatically attached. Text pasted into the prompt is included.

Requests use an ephemeral session without persistent URL caching or cookies and do not follow redirects. These client settings do not determine the provider’s retention, training or processing location. Review its current policy and account settings.

AI is optional

AI starts Off. Terminal and the rest of MARC remain usable without enabling it. Open Settings → Terminal & AI to choose a mode.

You can skip AI setup.

Monitoring, Files, Terminal, and supported controls work without an AI model or API key. Set up AI whenever you want suggestions.

Local AI with Ollama

Install and run Ollama on the selected Mac, install a model that fits its resources, and choose Local in Terminal & AI. MARC queries the installed-model list over SSH and sends generation requests to Ollama’s loopback service on that Mac. The model choice is remembered per Mac.

Local mode does not use MARC’s external API presets. The actual Ollama model, configuration and other software determine further network activity and logs; local mode is not a guarantee that every model configuration is offline.

API mode

The built-in presets are OpenAI, Google Gemini and Groq. Add a named key through Settings → Keychain → API Keys, then select it and a model in Terminal & AI. Custom mode accepts a compatible HTTPS chat-completions endpoint and a manually entered model ID.

API requests go directly from iPhone to the selected endpoint. The selected key must match that endpoint. A removed or unavailable selected key stops the request; MARC does not silently substitute a different saved secret. Provider access, model availability, quotas and charges depend on your account.

What you send

API requests send your prompt, selected model, and command-generation instructions to the configured provider, along with the API key when configured. Terminal output and files are not automatically attached. Review the provider’s privacy and retention terms.

See the AI privacy details.

Review before running

AI suggests a command; it does not execute it automatically. Tapping Run sends the command followed by Return to the active terminal. Read the entire command first. Use an empty shell prompt after exiting any running program and clearing partially typed input. MARC cannot detect what is reading the terminal.

Cancel a pending request or choose Off to stop future requests. Cancellation cannot recall data already transmitted. Deleting a local API key does not revoke the provider key or erase provider records.

Which mode should you choose?

Choose Off if you do not need suggestions. Choose Local if you want to use an Ollama model on your Mac. Choose API if you prefer a supported external provider.

Local models use your Mac’s memory and processing power. Start with a model that fits the machine, especially if other apps are already using a lot of RAM. A larger model is not always a better fit.

If local models do not appear

Check that MARC is connected to the intended Mac, Ollama is running there, and at least one model is installed. Then refresh the installed-model list in Terminal & AI.

The model list belongs to the connected Mac. A model installed on one Mac will not automatically appear on another.

Treat suggestions as a starting point

Explain what you want to do and review the result. If a command is unfamiliar, ask for an explanation before running it.

An AI response can use the wrong path, assume a tool is installed, or suggest an operation that changes more than you intended. You remain in control of whether the command runs.
